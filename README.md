# 🤖 Kleber.AI - Assistente Corporativo Inteligente

Este projeto é um Chatbot Corporativo desenvolvido para auxiliar em tarefas do dia a dia, consultas técnicas e organização de informações. Ele utiliza a tecnologia de ponta do **Google Gemini** para processamento de linguagem natural.

## 🚀 Tecnologias Utilizadas
* **Python:** Linguagem principal.
* **Streamlit:** Framework para interface web interativa.
* **Google Gemini 2.5 Flash:** Modelo de IA generativa de alta performance e baixa latência.
* **CSS Personalizado:** Interface customizada em Dark Mode.

## ⚙️ Funcionalidades
* 💬 **Chat Interativo:** Conversa fluida com memória de contexto (lembra das mensagens anteriores).
* 📅 **Consciência Temporal:** O sistema identifica a data e hora atual para respostas precisas.
* 🎨 **Interface Premium:** Design escuro com ícones personalizados para melhor experiência do usuário.
* ⚡ **Respostas Rápidas:** Integração otimizada com a API do Google.
